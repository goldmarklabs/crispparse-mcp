# CrispParse MCP Server (`@crispparse/mcp-server`)
Official Model Context Protocol (MCP) client wrapper for [CrispParse](https://crispparse.com) by GoldmarkLabs.
- **Endpoint:** `https://api.crispparse.com/v1/extract`
- **Discovery Manifest:** `https://api.crispparse.com/.well-known/mcp.json`
- **Auth:** Bearer Macaroon key (`CRISPPARSE_API_KEY`) or autonomous `x402` Base USDC micropayments.
